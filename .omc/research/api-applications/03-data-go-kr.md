## API 호출 주의사항

### Decoding vs Encoding 키 함정

공공데이터포털은 키를 두 종류로 제공함:
- **Encoding 키** (URL 인코딩됨) — 브라우저 주소창 복붙용
- **Decoding 키** (원본 문자열) — 코드에서 `httpx params=` 또는 `requests params=` 에 사용

```python
# 올바른 사용법 (Decoding 키)
params = {
    "serviceKey": os.getenv("DATA_GO_KR_DECODING_KEY"),  # Decoding 키
    "numOfRows": 100,
    "pageNo": 1,
    "type": "json",
}
response = httpx.get(BASE_URL, params=params)
```

> Encoding 키를 params에 넣으면 이중 인코딩으로 인증 오류 발생.
