## 2. 카피 (한국어, 3줄 이내)

### IMAGE (카메라 진단 결과)

```
※ AI 추정 결과이며 진단이 아닙니다.
※ 증상 의심 시 반드시 수의사 진료를 받으세요.
※ 사진 1장만으로 진단을 확정할 수 없습니다.
```

**왜 3줄인가**: 결과 카드 footer 영역 4-5줄 한도. 첫 줄 = 책임 범위, 둘째 줄 =
권장 행동, 셋째 줄 = 입력의 한계.

---

### AUDIO (오디오 진단 결과)

```
※ AI 추정 결과이며 진단이 아닙니다.
※ 호흡·기침이 의심스럽다면 즉시 수의사 진료를 받으세요.
※ 5–10초 녹음만으로 호흡기 질환을 확정할 수 없습니다.
```

---

### HOSPITAL (병원 매칭/리스트)

```
※ 영업/진료 시간은 변동될 수 있으니 방문 전 전화 확인을 권장합니다.
※ 응급 상황이라면 24시 동물의료센터로 즉시 연락하세요.
```

> 2줄 — 의료 진단이 아닌 위치 정보 카드라 책임 문구는 생략, 행동 권장 위주.

## 3. UI 가이드라인

- **위치**: 카드 가장 하단, 메인 콘텐츠와 12pt margin.
- **타이포**: 본문 font-size −2 (예: 14pt 본문 → 12pt 디스클레이머),
  semi-bold 가능. 색상은 secondary text token (`#666` light / `#999` dark).
- **줄별 정렬**: `※` 앞 padding-left 12pt 로 hanging indent 효과.
- **클릭 영역**: 비-인터랙티브. 링크 또는 버튼 금지 (오해 유발).
