## 2. 슬라이드별 메시지 상세

### S2 · 문제 제기 (문제의식 25점)
- 통계 1: 국내 반려동물 양육 가구 ~600만 (KB금융·통계청 인용 예정).
- 통계 2: 반려동물 1마리 평생 의료비 평균 1,000만원 이상 (KB펫보고서 등 실데이터 인용).
- 통계 3: 펫보험 가입률 1% 미만, 갑작스러운 진료비로 진료 포기·파양 사례 다수.
- 통계 4: 1인가구·고령자 반려인의 헬스 모니터링 부재.
- **문제 정의**: "사전에 알 수 있는 신호가 있어도 사람이 늦게 알아챈다 + 비용 충격에 대비가 안 돼 있다."
- 인용 출처는 KB펫금융보고서, 농림축산식품부 동물보호 국민의식조사, 통계청.

### S3 · 시장·트렌드
- 펫팸족 + 1인 가구 증가 → 반려동물 가족화.
- 웨어러블·IoT 보급 (케어테일 등 국내 디바이스 출시).
- 정부의 반려동물 의료체계 개선 정책(보호자 부담 완화) 흐름.

### S4 · 솔루션 개요 (독창성 20)
- **3-axis 결합도**:
  - X축: 데이터 (워치·홈캠·식이·진료 기록)
  - Y축: AI (질병 예측 → 의료비 예측 → 행동 권장)
  - Z축: 핀테크 (적금·보험·후원)
- 경쟁 차별화: 단순 펫케어 앱(펫스타·도그메이트) 또는 단순 펫보험과 달리, **"AI 신호→돈 결정"** 까지 한 흐름으로 잇는다.

### S5 · 사용자 시나리오 (스토리보드 7컷)
1. 보리네 엄마, 카카오 로그인 + 가족 멤버 초대.
2. 보리(시바, 4살) 프로필 등록, 케어테일 워치 연동.
3. 워치가 활동 감소·심박 이상 감지 → AI 분석.
4. 앱 푸시: "위장 트러블 가능성 12% — 1주 관찰 권장 / 가까운 OO병원 추천".
5. 앞으로 12개월 예상 의료비 표시 + "월 4.2만원 자동 적금" CTA.
6. 가족 캘린더에 산책·약 일정 분담, 동생이 오늘 산책 위임 받음.
7. 건강 목표 달성 → 보호소 후원 1,000원 캠페인 참여.

### S6 · 핵심 기능 5개
- ① **카메라 기반 질병 의심 분류** (피부/눈/귀/잇몸 정지 사진 → 이미지 분류 모델)
- ② **음성 기반 호흡 이상 분류** (기침/숨소리 5–10초 → 오디오 분류 모델)
- ③ 사료 종류 기반 식이 관리 + 진단 입력 합류 (FatSecret + 자체 200건 시드)
- ④ 진단 결과 기반 동물병원 매칭 (진료과 표기 + 카카오맵 + 공공데이터)
- ⑤ (옵셔널) 워치 시계열 생체 카드 (Caretail 연결 시) / **의료비 예측 + 적금은 본선 공개**

### S7 · 기술 아키텍처 (실현가능성 25)
- 모바일 RN + 클라우드 FastAPI + RTX 5090 로컬 AI 서버 하이브리드 구조 다이어그램.
- 외부 API 5종(케어테일/카카오/공공데이터/FatSecret/오픈뱅킹) 결합 표.
- 보안·프라이버시: 로컬에 raw 보관, 클라우드는 메타·집계만. JWT + RBAC.

### S8 · AI 모델 차별점 (독창성 20)
- **멀티모달 진단 파이프라인** 다이어그램:
  - 입력 1: 카메라 이미지 (피부/눈/귀/잇몸 4부위) → MobileNetV3-Small fine-tune → top-3 의심 라벨
  - 입력 2: 음성 5–10초 클립 (기침/호흡) → YAMNet + 분류 헤드 → 이상 점수 + 카테고리
  - 입력 3 (옵셔널): 워치 시계열 → IsolationForest anomaly (디바이스 연결 시)
  - 출력: 진단 카드 + 진료과 매칭 + 가까운 병원 추천
- 로컬 RTX 5090 자체 fine-tuning + 공개 데이터셋 활용 (Kaggle dog skin disease, dog cough audio).
- 의료적 디스클레이머 의무 노출 ("AI 추정치, 수의사 상담 권장").
- 본선 단계: 워치 시계열 anomaly 부활 + 의료비 예측 결합으로 진단→비용 흐름 완성.

### S9 · 핀테크 결합 (독창성·영향력)
- **AI 위험치 → 자동 적금 권장** 한 줄 흐름.
  - 예: "보리는 향후 12개월 의료비 p90 50만원 예상 → 월 4.2만원 적금"
- 오픈뱅킹/제휴 적금 가입 페이지 연동 (PoC).
- **donation 도메인 일치**: 건강 목표 달성 마일리지 → 유기견 보호소 후원 매칭.
- 포용금융 메시지: 펫 의료비로 인한 진료 포기·파양·재정 충격 완화.

### S10 · BM·확장성 (영향력·확장성 20)
- **수익 모델**:
  - B2C: 프리미엄 구독(고도 AI 분석/멀티펫/가족 무제한)
  - B2B: 동물병원·펫샵 SaaS 라이선스 (Phase 3)
  - 제휴: 펫보험·은행 적금 상품 광고/수수료
- **확장성**:
  - 멀티펫·멀티종(고양이·소형동물)
  - 홈캠+YOLO 식사 모니터링(Phase 2)
  - 펫보험 비교, BNPL 진료비 분할결제 (Phase 3)
  - 한국 → 일본·동남아 펫 시장 확장

### S11 · 일정·팀 (실현·성실성)
- 24일 MVP 동작 + 6.5 발표 + 8.28 본선 시연.
- 팀 역량 매트릭스: 백엔드 / AI/ML / 모바일 / 디자인·기획.
- 자문/네트워크: 수의사 어드바이저 1인 확보 계획.

### S12 · 클로징
- "건강을 미리 알고, 비용을 미리 모으고, 사랑을 함께 나눈다."
- 다음 단계: PoC 시연 영상 / 베타 모집 / 추가 데이터셋 확보.
