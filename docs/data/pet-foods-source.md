# Pet Foods Seed Data — 출처 메모

## 개요

- 총 **200건** 시드 데이터 (브랜드 사료 + 간식 + 일반식)
- 출처: **[추정]** — 브랜드 공식 사이트 + 국내 펫샵(쿠팡/네이버쇼핑/펫프렌즈) 표기 기반
- 본 데이터는 W2 Day 2 lead 검수 전 1차 초안입니다.

## 검수 계획

- **W2 D2 lead**: 5개 샘플 무작위 추출 → 브랜드 공식 영양성분표와 대조 → 오차 정정 메모 이 파일에 추가
- 본선 통과 시 공식 영양성분표 표기로 정확도 향상 예정
